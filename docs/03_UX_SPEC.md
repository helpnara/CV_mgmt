## 1. 원칙

1. **한 줄이면 저장된다.** 기록 입력은 어느 화면에서든 두 번 이내 클릭으로 닿고, Enter 한 번으로 저장된다.
2. **보여 주고 복사한다.** 프롬프트와 내보내기 파일은 전문을 먼저 보여 준다. 보지 않고 누르는 복사 버튼은 없다.
3. **숫자는 링크다.** 화면의 모든 개수는 눌리고, 누르면 그 개수만큼의 목록이 나온다.
4. **물어볼 것이 맨 위다.** 경험 상세에서 "확인 필요"와 정합성 경고가 본문보다 위에 있다.
5. **상태는 글자로도 말한다.** 색만으로 구분하지 않는다. 상태 딱지에는 낱말이, 경고에는 ⚠와 문장이 있다.
6. **원본은 손대지 않는다.** 기록 원문은 읽기 전용으로 보이고, AI가 채운 값과 사용자가 고친 값은 구분된다.

## 2. 전역 요소

### 2.1 헤더 (sticky)

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ 느린 길   홈  기록  정리  경험  내보내기  더보기▾        [🔍 검색        ]  vault: D:\느린길 │
└──────────────────────────────────────────────────────────────────────────────┘
```

- 메뉴 순서는 사용 빈도 순이다. 더보기: 경력·과제 / 역량 / 설정·점검.
- "정리" 옆에는 정리되지 않은 기록 수가 작은 딱지로 붙는다(0이면 없음).
- 검색은 기록 원문·경험 전체를 대상으로 하고 결과는 경험 목록 화면에 "검색: …" 조건으로 연다.
- vault 경로는 1093px에서 말줄임, 마우스를 올리면 전체.

### 2.3 상태 표현

| 요소 | 표현 |
|------|------|
| 경험 상태 | 딱지: `초안`(회색 테두리) / `구조화`(노랑 바탕, 진한 갈색 글자) / `확정 ✓`(초록 바탕) |
| 출처 | 작은 회색 글자: 기록 / 분해 / 수동 |
| 정량 성과 기준 종류 | 칩: `비교` / `집계` / `조건` / `미확인 ?`. 미확인만 노랑 |
| 경고 | ⚠ + 한 문장 + [확인함] |
| AI가 채운 값 | 입력칸 왼쪽에 2px 파란 세로줄. 사용자가 한 번이라도 고치면 줄이 사라진다 |
| 확인 필요 | 노랑 카드, 질문마다 한 줄 |

색 조합은 느린 나이테 토큰(`--warn`, `--accent-soft` 등)과 딱지 팔레트를 토큰으로 승격해 쓴다. 명암비 AA는 UI 시험이 실제 렌더 색으로 잰다.

### 2.4 단축키

| 키 | 동작 |
|----|------|
| Ctrl+S | 현재 화면 저장 (경험 상세, 경력·과제 편집, 설정) |
| Enter | 기록 저장 (메모 종류일 때). Shift+Enter 줄바꿈 |
| Ctrl+Enter | 기록 저장 (경력기술서 종류일 때, 긴 붙여넣기 보호) |
| Alt+N | 어디서든 빠른 기록 창 열기 |
| / | 검색창으로 |

### 2.5 공통 상태

- **로딩**: 표·카드 자리에 회색 줄 3개. 0.3초 안에 끝나면 보이지 않는다.
- **불러오기 실패**: `LoadError` (사유 + [다시 시도]). 빈 목록과 구분된다.
- **빈 목록**: 왜 비었는지 + 다음 행동 버튼 하나.
- **저장 실패**: Toast + 입력 내용 유지. 떠나기 경고(`useUnsaved`).
- **서버 꺼짐**: "프로그램에 연결하지 못했습니다 — 느린 길 창(run.bat)이 켜져 있는지 확인하세요".

- 종류가 `경력기술서`면 입력칸이 20줄로 커지고 저장 키가 Ctrl+Enter로 바뀐다. 저장 뒤 "분해 프롬프트를 만들까요? [분해하기]" 토스트.

**① 프롬프트**
- 기록 정리 모드: 대상 기록들 + 역량 사전 + 최근 경험 20건(ID·제목·기간)이 채워진 structure_entry 프롬프트. 경력기술서 분해 모드: 대상 기록 하나 + decompose_cv v0.2 프롬프트.
- 전문은 고정폭 아닌 본문 서체, 연한 바탕, 최대 높이 360px 스크롤. 복사 버튼은 전문 아래에만 있다(원칙 2).
- 복사하면 버튼이 "복사됨 ✓"로 바뀌고 ② 칸에 포커스가 간다.
- 분해 모드에서는 FR-D6 서비스별 안내가 ① 아래에 접힌 상태로 붙는다.

**② 응답 붙여넣기**
- [읽기]를 누르면 파서(스펙 3.3)가 돌고 ③이 채워진다. 붙여 넣는 즉시 원문이 `AI 응답` 기록으로 저장된다(FR-B3). 사용자가 ③에서 아무것도 저장하지 않고 떠나도 원문은 남는다.
- 분해 모드에서 AI가 "계속"으로 나눠 출력하면 [더 붙여넣기]로 응답을 누적한다. 미리보기는 누적 블록 전체를 보인다. 같은 제목의 블록이 다시 오면 중복 후보로 표시한다(02 §12 미결의 잠정안).
- 블록이 하나도 없으면 ③ 자리에 "형식 블록이 없습니다. ①의 프롬프트를 처음부터 다시 붙여 넣었는지 확인하세요" + 원문 일부.

**③ 미리보기·저장**
- 위 요약 줄: 블록 수, 읽은 줄, 못 읽은 줄, 중복 후보, 새 역량 후보, (분해 모드) 누락 후보. 모두 눌러서 해당 카드로 스크롤.
- **블록 카드**: 제목, 기간, 역할 한 줄, AI의 `이어짐` 제안, 저장 방법 라디오(새 경험 / 기존 경험에 이어서 [고르기] / 버림), 확인 필요·정량·역량 개수. [펼치기]로 전 필드를 읽기 전용으로 본다.
- 역할에 주체 구분이 없으면 카드에 "⚠ 본인이 한 일과 다른 주체가 한 일을 구분해 주세요"(FR-C10). 저장은 막지 않는다. 확정 단계에서 막는다.
- **이어서 저장할 때 충돌**: 기존 경험에 사용자가 고친 필드가 있으면 카드가 넓어지며 필드별 비교가 나온다. `기존 값 | AI 값` 두 칸, 기본 선택은 기존 값(FR-C7).
- **누락 후보**(분해 모드, FR-D4): 원문에서 뽑은 수상·특허·발표·과제명 중 어느 블록 제목·증빙에도 없는 것. 각 항목 옆에 [빈 경험으로 만들기].
- **새 역량 후보**: 칩으로 보이고, 누르면 [사전에 추가] / [기존 역량으로: ▾].
- 저장 버튼은 "버림"이 아닌 블록 수를 센다. 저장하면 경험이 `구조화` 상태로 생기고, 토스트 "경험 n건을 저장했습니다 [목록에서 보기]".

1093px에서 왼쪽 약 456px, 오른쪽 약 581px. 1440px 이상에서는 본문 최대 폭 1720px까지 넓어지고 비율은 유지한다.
