# 프롬프트: 기존 프로젝트("느린 나이테") 프로파일 추출

> 용도: 느린 길(Slow Way)을 같은 스택과 디자인으로 만들기 위해, 기존 웹 앱 "느린 나이테"의 구조를 Markdown 한 파일로 정리한다.
> 사용법: "느린 나이테" 저장소를 연 Claude Code(또는 저장소를 읽을 수 있는 AI)에 아래 프롬프트를 그대로 붙여 넣는다. 결과 파일 `project-profile.md`를 공유한다.
> 주의: 비밀값(API 키, 토큰, 비밀번호, 접속 문자열)은 절대 포함하지 않는다. 환경 변수는 이름만 적는다.

너는 이 저장소("느린 나이테")를 분석해서, 같은 스택과 디자인으로 새 웹 앱을 만들 개발자에게 넘길 "프로젝트 프로파일" 문서를 작성한다.
결과는 저장소 루트에 `project-profile.md` 한 파일로 저장하고, 한국어로 쓴다.

절대 규칙: API 키, 토큰, 비밀번호, DB 접속 문자열, 서비스 계정 JSON 같은 비밀값은 어떤 형태로도 문서에 넣지 않는다. 환경 변수는 이름과 용도만 적는다. .env 파일의 값은 읽어도 적지 않는다.

다음 순서와 제목으로 작성한다.

# 1. 개요
- 앱 이름, 한 줄 설명, 배포 URL(있다면), 저장소 구조 요약(최상위 폴더와 역할)
- 사용자 플로우 핵심 3~5개 (예: 로그인 → 기록 → 목록 → 내보내기)

# 2. 기술 스택
- 언어와 버전 (package.json / 설정 파일 기준)
- 프런트엔드 프레임워크와 버전, 라우팅 방식, 상태 관리
- 스타일링 방식 (CSS 프레임워크, CSS-in-JS, 디자인 토큰 파일 위치)
- UI 컴포넌트 라이브러리
- 빌드 도구, 패키지 매니저, 린트/포맷 설정
- 테스트 도구와 테스트 범위
- 주요 의존성 목록 (package.json dependencies 전체를 표로)

# 3. 백엔드와 데이터
- 백엔드 유형 (서버리스 / BaaS / 자체 서버 / 없음)과 제공자 (예: Supabase, Firebase, Vercel Functions)
- 인증 방식 (제공자, 소셜 로그인 종류, 세션 저장 방식)
- 데이터베이스 종류와 스키마: 테이블/컬렉션 이름, 주요 컬럼, 관계. 스키마 파일이나 마이그레이션이 있으면 경로 표시
- 접근 제어 (RLS 정책, 보안 규칙) 요약
- 로컬 저장소 사용 여부 (localStorage, IndexedDB)와 용도
- 파일 저장(스토리지) 사용 여부
- 데이터 내보내기/가져오기 기능이 있다면 형식과 구현 위치

# 4. AI 연동 (있다면)
- 사용 제공자와 모델 이름
- 호출 경로: 브라우저에서 직접 / 서버 함수 경유. 키를 어디에 두는지(이름만)
- 프롬프트가 있는 파일 경로와 역할 요약 (프롬프트 본문은 복사하지 말고 어떤 일을 하는지만)
- 구조화 출력(JSON) 사용 여부, 스트리밍 여부
- 사용량 제한, 비용 통제 장치가 있는지
- 없으면 "AI 연동 없음"

# 5. 배포와 운영
- 호스팅 제공자, 배포 방식 (Git 연동 자동 배포 / CLI), 브랜치 전략
- CI 설정 (GitHub Actions 등) 파일 경로와 하는 일
- 환경 변수 목록: 이름, 용도, 어디서 쓰이는지 (값은 절대 적지 않음)
- 도메인, 분석 도구, 에러 수집 도구
- 월 운영 비용 구조 (무료 티어 여부 등, 코드나 문서에서 확인되는 범위에서)

# 6. 디자인 시스템
- 색상 토큰 전체 (이름과 값), 라이트/다크 모드 처리 방식
- 서체 (폰트 이름, 로딩 방식, 크기 체계)
- 간격, 모서리, 그림자 체계
- 레이아웃 구조 (헤더/사이드바/바텀 탭 등), 반응형 기준점
- 재사용 컴포넌트 목록과 경로 (버튼, 카드, 입력, 모달, 리스트 등)
- 아이콘 세트
- 디자인 토큰이 파일로 분리되어 있으면 그 파일 전체 내용을 코드 블록으로 포함

# 7. 공통 패턴
- 폴더 구조 규칙, 파일 명명 규칙
- 데이터 접근 계층 패턴 (훅, 서비스 레이어 등)
- 에러 처리와 로딩 상태 처리 방식
- 날짜/시간 처리, 한국어 처리(정렬, 입력)
- PWA/오프라인 지원 여부 (manifest, service worker)
- 접근성 처리 수준

# 8. 재사용 가능 자산
